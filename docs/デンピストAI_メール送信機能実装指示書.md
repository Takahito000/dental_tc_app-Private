# デンピストAI メール送信機能 実装指示書（Kimi Code用）

## 背景・目的
現在「PDFをメール送信」ボタンは外部サービス（n8n）のWebhookを呼んでいる。これを**自前のAPIルート＋Resend（メール送信API）に置き換え**、n8nへの依存を解消する。トリガーは従来通り「医院スタッフがボタンを押下した時のみ」（任意送信）。自動送信は一切行わない。

## 全体像
1. ブラウザで生成済みのPDF（jsPDFで生成している既存処理）を新APIにPOST
2. 新APIがSupabaseから対象医院のメールアドレスを取得
3. ResendでPDF添付メールを送信
4. 結果を画面にフィードバック

---

## ステップ1: Resendライブラリの導入
- `resend` パッケージが必要。**npm install は必ず私（ユーザー）に確認してから実行すること**（自動実行禁止）
- 承認後: `npm install resend`

## ステップ2: 環境変数
以下を `.env.local` に追加するのは**私が手動で行う**。あなたは値を表示・要求しないこと（.env系ファイルの中身を表示するコマンドは禁止。キー名のみ扱う）。

- `RESEND_API_KEY` … Resendで発行したAPIキー
- `MAIL_FROM` … 送信元アドレス（例: `デンピストAI <report@mail.denpist-ai.com>`）

Vercel側の環境変数設定も私が手動で行う。必要なキー名の一覧だけを報告すること。

## ステップ3: APIルート新設 `app/api/send-pdf/route.ts`
### 入力（POST body / multipart または JSON+base64。既存のPDF生成処理に合わせて実装し、採用した方式を報告すること）
- `pdfData`: PDFのバイナリ（base64推奨）
- `clinicId` または既存の識別子: 医院のメールアドレスをSupabaseから引くためのキー
- `fileName`: 添付ファイル名（例: `AI客観分析レポート_20260901_A107.pdf`。管理IDを含める）
- 件名・本文のテンプレートはコード側の定数とする（AI生成させない）

### 処理
1. バリデーション（pdfData存在確認、サイズ上限 5MB程度）
2. Supabaseから医院メールアドレスを取得（既存の医院マスタのカラム名は**コード内を調査して特定し、私に報告してから進めること**。推測で実装しない）
3. Resendで送信（添付: `attachments: [{ filename, content: <base64> }]`）
4. 成功/失敗をJSONで返す（`{ ok: true }` / `{ ok: false, error: "..." }`）

### メール文面（定数・この文言で固定）
- 件名: `【デンピストAI】AI客観分析レポート（{{管理ID}}）`
- 本文:
```
AI客観分析レポートのPDFを添付でお送りします。
印刷のうえ、患者様へのご提示にご利用ください。

管理ID: {{管理ID}}
発行日: {{発行日}}

※このメールはデンピストAIの送信ボタン操作により送信されました。
```

## ステップ4: フロントの送信ボタン差し替え
- 既存のメール送信ボタンの呼び出し先を n8n Webhook から `/api/send-pdf` に変更
- 既存のPDF生成処理（jsPDF + html2canvas）はそのまま流用し、生成したPDFをAPIに渡す
- 送信中はボタンを「送信中…」にして二重押下を防止
- 完了時に「医院のメールアドレス宛に送信しました」、失敗時に「送信に失敗しました。時間をおいて再度お試しください」をトースト等で表示
- **指定のない文言の追加は禁止。表示文言を追加・変更したい場合は必ず事前に私へ確認すること**

## ステップ5: 確認（各ステップ完了時に必ず実行）
- `npx tsc --noEmit` が通ること（エラーがあれば修正してから次へ）
- 実装完了後、以下を報告:
  1. 採用したPDF受け渡し方式（base64 / multipart）
  2. Supabaseの医院メールアドレスの取得元テーブル・カラム名
  3. 追加した環境変数のキー名一覧（値は不要）
  4. tsc通過の結果

## 禁止事項（厳守）
- n8n関連のコード・環境変数の**削除は今回行わない**（動作確認が取れるまで残す）
- git push・デプロイ・npm install は私の承認なしに実行しない
- .env系ファイルの中身を表示するコマンドは実行しない
- メール送信の自動化（バッチ・定期実行・生成後の自動送信）は実装しない
