## 0. プロジェクト概要

- **目的**：歯科医院向けAIカウンセリング支援ツール「デンピストAI」のランディングページ（LP）を新規作成する
- **対象読者**：歯科医院の院長（個人立中心）。多忙。医療倫理への意識が高く、「売り込み」「心理誘導」的な商業表現に強い警戒心を持つ
- **公開目標**：2026年10月頭
- **ドメイン**：denpist-ai.com（既にVercelでツール本体が稼働中）

## 1. 技術構成（厳守）

### 1-1. 既存環境

- Next.js 16.3.1（App Router）/ Tailwind CSS v4 / Vercel / Supabase
- 現在、ツール本体がルート（`/`）で稼働中
- APIルート：`/api/counseling`、`/api/send-pdf`

### 1-2. ディレクトリ変更（本タスクの核心）

| 変更前 | 変更後 |
|---|---|
| ツール本体：`/` | ツール本体：`/app` に退避 |
| （なし） | LP：`/` に新設 |

- LPとツールは**同一リポジトリ・同一Vercelデプロイ**で運用する
- ツール退避に伴い、内部リンク・認証後の遷移先・APIパスが壊れないよう全点検すること

### 1-3. 既存トークンURLのリダイレクト

- 既存利用者に配布済みのURL：`https://www.denpist-ai.com/?t=xxxxxxxxxx`
- **middlewareを実装**し、ルートへのアクセスでクエリパラメータ `t` が存在する場合のみ `/app?t=xxx` へリダイレクトすること（トークンを引き継ぐ）
- `t` パラメータなしのルートアクセスはLPを表示する

### 1-4. 計測

## 2. デザイン方針

### 2-1. 配色・トーン（厳守）

- **既存ツールの配色をそのまま踏襲すること**。`globals.css`（Tailwind v4のカラー変数）に定義済みのカラーパレットを読み込み、LPでも同一の変数を使用すること
- **新規の色を勝手に追加しない**
- 基調：クリーム／ベージュ系の暖色、アクセントに茶・ゴールド系
- 添付のツール画面スクリーンショットおよび「AI客観分析レポート」画像（A4・茶ゴールド系）を参照し、トーンを合わせること

### 2-2. タイポグラフィ

- 見出し：明朝体系（ツールのロゴが明朝体のため統一感を持たせる）。既存ツールで明朝体フォントを使用している場合は同じものを流用
- 本文：可読性優先のゴシック体
- 行間・余白は広めに取り、高級感と落ち着きを優先する

### 2-3. 全体的な品質基準

- 「医療ツールらしからぬ柔らかさ」と「高級感」の両立が目標
- 派手なアニメーション、ポップな配色、B2C的な煽り表現は禁止
- モバイルファーストで設計（院長はスマホで見る可能性が高い）

## 4. 禁止表現リスト（コンプライアンス厳守）

以下は法的リスクまたは医療倫理上の反発を招くため、**LP・生成物・メタ情報を含め一切使用禁止**：

| カテゴリ | 禁止表現例 | 理由 |
|---|---|---|
| 効果保証 | 「成約率が必ず上がる」「誰でも自費率3倍」「導入するだけで売上増」 | 独禁法（ぎまん的顧客誘引）・不正競争防止法 |
| 診断主体の誤認 | 「AIが最適な治療計画を診断・決定」「ドクターの判断不要」 | 薬機法（SaMD）該当リスク・医師法 |
| 保険診療の毀損 | 「保険の義歯は粗悪」「銀歯は体に悪い」 | 医療広告ガイドライン（誇大広告）・療担規則 |
| 比較優良 | 「業界No.1」「他社ツールより優れている」（根拠なし） | 景表法・不競法 |
| 心理誘導の明示 | 「患者の心理を突いて高額治療を即決させる」「クロージングトークを自動生成」 | 消費者契約法・倫理的反発 |
| 団体の公式推薦 | 「TC協会推薦」「北海道支部公認」等 | 推薦はあくまで個人の立場 |
| 実績数値の乱用 | 監修者プロフィール以外の箇所での実績数値 | 根拠提示義務 |
| 医院名の掲載 | 導入医院の実名 | 許諾未整備のため |

**表現の型として守ること**：
- 主語は「成約」ではなく「選択肢の提示」
- 数値を使う場合は必ず根拠（調査主体・期間・母数）を併記
- 「保険診療は国が定めた標準的な医療として有効」という前提を崩さない
